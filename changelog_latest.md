##  Features ✨
* Added drawing export from one pane that remembers format and scope for that drawing.
* Added a headless PNG export that returns an image, and the assistant exports a framed region when reading objects is not enough.
* Added multimodal assistant profiles so text-only models stay text-only.
* Added paste and preview for chat images.
* Added tool images on the user message after the whole tool batch.
* Added drawing-region references in chat. The chip draws its box only on that drawing.

## Improvements 🛠
* Fixed canvas clipboard shortcuts so copy stays on the canvas, and pasting in chat does not also paste on the drawing.
